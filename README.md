# NexaShop Demo

Este repositorio contiene una demo funcional del proyecto NexaShop, una plataforma de comercio electrónico con integración de pagos.

El proyecto original no puede ser compartido públicamente por razones de contrato y confidencialidad, por lo que esta versión es solo una muestra para fines educativos y de portafolio.


## Descripción

NexaShop es un sistema de e-commerce diseñado para la venta de productos en línea de forma simple y eficiente.  
Esta demo representa la estructura y el flujo principal del proyecto real.

Incluye:
- Tienda virtual
- Carrito de compras
- Gestión básica de productos
- Flujo de compra simulado
- Integración de pagos demostrativa

---

## Instalación

Para usar este proyecto necesitas:

1. Descargar el frontend.
2. Descargar el backend.
3. Importar el archivo SQL de la base de datos y generar la bd.
